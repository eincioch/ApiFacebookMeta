## 📞 Soporte y Contribución

### 🐛 Reportar Problemas
- Revisa primero [INSTALLATION.md](INSTALLATION.md) para problemas comunes
- Crea un issue en GitHub con detalles específicos
- Incluye logs y pasos para reproducir el problema

### 🤝 Contribuir al Proyecto
- Fork el repositorio
- Sigue las convenciones de arquitectura en [ARCHITECTURE.md](ARCHITECTURE.md)
- Prueba tus cambios con los ejemplos de [EXAMPLES.md](EXAMPLES.md)
- Crea un Pull Request con descripción detallada

### 📚 Mejorar la Documentación
- La documentación está en formato Markdown
- Sigue la estructura existente
- Incluye ejemplos prácticos cuando sea relevante
- Mantén la consistencia en el estilo

## 🔄 Mantenimiento de la Documentación

Esta documentación se mantiene actualizada con cada release del proyecto. Si encuentras información desactualizada:

1. Verifica la versión del proyecto en [README.md](../README.md)
2. Consulta el changelog en GitHub releases
3. Reporta discrepancias como issues
4. Contribuye con actualizaciones via Pull Request
